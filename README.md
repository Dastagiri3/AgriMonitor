# 🌾 AgriMonitor

AgriMonitor is a smart agriculture monitoring platform designed to help farmers make data-driven decisions using weather information, crop recommendations, sensor monitoring, and farm analytics.

The platform provides real-time agricultural insights through an easy-to-use web interface, enabling farmers to improve productivity, optimize resource usage, and monitor farm conditions effectively.

## 📖 Project Overview

AgriMonitor aims to modernize farming by providing:

- Real-time farm monitoring
- Weather forecasting integration
- Crop recommendations
- Sensor data visualization
- Alert and notification system
- Farmer dashboard
- Sustainable farming insights

The platform can be used with simulated sensor data or integrated with actual IoT devices in future implementations.

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/Dastagiri3/AgriMonitor.git
```

### Navigate to Project

```bash
cd AgriMonitor
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm start
```

Application will run on:

```text
http://localhost:3000
```

---

## 🔑 Environment Variables

Create a `.env` file in the root directory.

```env
REACT_APP_SUPABASE_URL=your_supabase_url

REACT_APP_SUPABASE_ANON_KEY=your_supabase_anon_key

REACT_APP_WEATHER_API_KEY=your_weather_api_key
```
